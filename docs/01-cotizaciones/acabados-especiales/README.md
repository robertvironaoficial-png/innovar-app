# Categoría 03 — Acabados Especiales

## Estado

**Documentación activa.**

Esta carpeta corresponde a la tercera categoría del módulo **Cotizaciones** que será organizada de manera profesional dentro del repositorio.

## Propósito

Documentar la lógica comercial y funcional necesaria para cotizar **Acabados Especiales**, entendidos como complementos premium que se agregan principalmente a cocinas integrales para mejorar su funcionalidad y estética.

## Fuente de verdad inicial

La categoría se construye a partir de la documentación comercial entregada por el cliente, donde se detallan:

- Definición de la categoría.
- Componentes incluidos.
- Puertas de aluminio + vidrio.
- Cálculo por metro cuadrado.
- Bisagras adicionales según altura.
- Iluminación LED por metro lineal.
- Casos de uso reales.
- Estructura esperada del ítem.
- Fórmulas de automatización.
- Validaciones.
- Flujo de cotización.

## Objetivo documental de esta carpeta

Convertir la información de negocio en documentos que puedan ser utilizados por:

- Dirección del proyecto.
- Producto.
- Diseño funcional.
- Ingeniería frontend.
- Ingeniería backend.
- QA funcional.
