# Módulo 01 — Cotizaciones

## Propósito

Este módulo documenta de forma profesional el sistema de cotizaciones de Innovar App, separando:

- Reglas de negocio.
- Categorías comerciales.
- Fórmulas de cálculo.
- Validaciones funcionales.
- Responsabilidades futuras de frontend y backend.
- Riesgos de implementación.
- Criterios para construir un motor de cotización robusto.

## Objetivo estratégico

El módulo **Cotizaciones** será el primer dominio del sistema que se documentará de punta a punta antes de avanzar hacia implementación o migración técnica.

La intención es dejar preparado el terreno para que, en una fase posterior:

- El frontend se concentre en experiencia de usuario y captura de datos.
- El backend sea la autoridad del cálculo oficial.
- Las reglas de cada categoría queden versionadas, trazables y reutilizables.

2. Acabados Especiales.

La documentación avanzará categoría por categoría.

## Criterio de avance

Una categoría se considerará suficientemente documentada cuando tenga:

1. Fuente de verdad funcional normalizada.
2. Glosario de términos de negocio.
3. Reglas de cálculo formalizadas.
4. Entradas requeridas.
5. Salidas esperadas.
6. Validaciones.
7. Casos de prueba funcionales.
8. Preguntas abiertas y decisiones pendientes.
9. Propuesta de contrato futuro frontend-backend.
10. Riesgos de implementación identificados.
