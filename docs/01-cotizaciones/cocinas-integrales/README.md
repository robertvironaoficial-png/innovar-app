# Categoría 01 — Cocinas Integrales

## Estado

**Documentación activa.**

Esta es la primera categoría del módulo **Cotizaciones** que será trabajada de manera completa.

## Propósito

Documentar la lógica comercial, funcional y futura estructura de software necesaria para cotizar **Cocinas Integrales** de manera clara, consistente y preparada para convertirse posteriormente en un motor backend robusto.

## Fuente de verdad inicial

La categoría se construye a partir de la documentación comercial entregada por el cliente, donde se detallan:

- Tipos de cocina.
- Metrajes.
- Módulos especiales.
- Muebles lineales.
- Mesones.
- Recargos por profundidad.
- Islas y barras.
- Costos fijos.
- Transporte.
- Componentes adicionales.
- Puertas, tapas y acabados especiales asociados.

## Objetivo documental de esta carpeta

Convertir la información de negocio en documentos que puedan ser utilizados por:

- Dirección del proyecto.
- Producto.
- Diseño de software.
- Ingeniería frontend.
- Ingeniería backend.
- QA funcional.

## Alcance inmediato

En esta primera etapa de trabajo, el objetivo no es programar, sino:

- Ordenar la lógica.
- Detectar ambigüedades.
- Preparar el lenguaje común del sistema.
- Sentar la base para que la implementación futura sea estable y mantenible.
