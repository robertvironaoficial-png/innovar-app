## 1. Propósito

Esta carpeta agrupa la documentación de los módulos visibles en el **Hub de Configuración** de Innovar App.

Su objetivo es clasificar el sistema administrativo y sus piezas de soporte antes de profundizar módulo por módulo.

# 3. Clasificación funcional inicial

## 3.1 Catálogos Maestros

### Materiales e Insumos

Gestión de recursos disponibles para parametrización, acabados, herrajes y otros elementos de catálogo.

### Tarifario y Precios

Gestión de valores de referencia, precios, categorías y cambios históricos de tarifas.

### Días Festivos

Calendario de excepciones y días no laborables que pueden afectar agenda, tareas y disponibilidad.

## 3.2 Accesos y Seguridad

### Usuarios y Roles

Gestión de usuarios internos, perfiles y niveles de acceso.

### Auditoría del Sistema

Registro de acciones críticas, cambios y trazabilidad operativa.

### Notificaciones WhatsApp

Gestión del canal de mensajería y trazabilidad de envíos, estados y plantillas.
