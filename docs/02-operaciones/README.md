# Operaciones — Mapa Global

## 1. Propósito

Esta carpeta agrupa la documentación de los módulos visibles en el **sidebar operativo** de Innovar App.

Su objetivo es clasificar el sistema tal como lo percibe el usuario final, antes de profundizar módulo por módulo.

# 3. Clasificación funcional inicial

## 3.1 Dashboard

Vista de resumen del sistema. Probablemente concentra indicadores, estados y accesos rápidos.

## 3.2 Proyectos

Gestión del ciclo de vida de proyectos activos, aprobaciones, diseño, producción, instalación y entrega.

## 3.3 Clientes y Ventas

### Directorio

Gestión de clientes finales y su información básica.

### Solicitudes / Leads

Gestión de prospectos, urgencias, asignaciones y evolución comercial.

### Cotizaciones

Gestión de cotizaciones y productos configurables. Este módulo se documenta en carpeta propia.

## 3.4 Agenda y Tareas

### Citas

Coordinación de reuniones, visitas y agendas asociadas a clientes o proyectos.

### Tareas

Seguimiento operativo de pendientes, responsables, prioridades y estados.

## 3.5 Finanzas

### Pagos

Registro de ingresos por proyecto o cliente.

### Gastos

Registro de egresos, categorías y aprobaciones.

### Cierres contables

Resumen financiero y cierre económico por proyecto.

Cada módulo operativo deberá contar, más adelante, con:

1. Propósito funcional.
2. Pantallas relacionadas.
3. Tablas asociadas.
4. Flujos principales.
5. Reglas de negocio.
6. Automatizaciones relacionadas.
